# Tests Directory

This directory is reserved for the automated testing suite of the Food Discovery Platform.

## Roadmap

- **Unit & Component Testing:** Vitest + React Testing Library for UI components and business utilities.
- **Integration Testing:** Verification of data ingestion and filtering workflows.
- **End-to-End Testing:** Playwright for critical discovery journeys (searching dishes, filtering by verification tier, inspecting local food spots).

See [docs/development/testing-strategy.md](../docs/development/testing-strategy.md) for full architecture and test conventions.
